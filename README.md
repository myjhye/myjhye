## About Me

AI 에이전트를 설계하고, 프로덕트를 만들어 수익화하는 개발자

LangGraph 멀티스텝 에이전트, pgvector RAG, Langfuse 관측성, SSE 스트리밍 등 AI 엔지니어링 핵심 기술을 실제 동작하는 프로덕트로 구현합니다. <br />
단순 기능 구현보다 관측 가능하고 운영 가능한 시스템 설계에 집중합니다.

Apps In Toss에 미니앱을 다수 런칭하여 광고 수익 운영 중입니다.

## Tech Stack

**AI / Agent** — LangGraph, OpenAI API, RAG (pgvector), Langfuse, SSE

**Backend** — Python, FastAPI, PostgreSQL, Spring Boot

**Frontend** — React, TypeScript, React Native

**Infra** — Railway, Vercel, Docker
